A token launch radar: it ranks the protocols that record no token by an implied value fitted to the snapshot itself (a power law over TVL, adjusted by 7-day growth and age), with a concrete farm plan per protocol and a static dashboard to browse it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input input/snapshot.json
```
